
AQUA-SCAN 
AI-Powered Autonomous Underwater Dam Inspection System
See beneath the surface. Detect before disaster.
Overview
AQUA-SCAN is a software prototype that simulates an autonomous underwater ROV for inspecting dam structures in low-visibility conditions. It demonstrates underwater navigation, obstacle awareness, potential defect identification, and inspection reporting.
Key Features
- 3D underwater dam and ROV simulation.
- Simulated sonar visualisation.
- Defect monitoring: cracks, erosion, spalling, and suspected seepage.
- Rule-based risk assessment.
- OpenCV-based image enhancement (if integrated).
- Downloadable CSV inspection reports.
Technology Stack
- Python
- Streamlit
- Plotly
- OpenCV
- NumPy
- NetworkX (if used)
Installation
git clone https://github.com/YOUR-USERNAME/AQUA-SCAN.git
cd AQUA-SCAN
pip install -r requirements.txt


Run
streamlit run aquascan2.py


Open http://localhost:8501 in your browser.
